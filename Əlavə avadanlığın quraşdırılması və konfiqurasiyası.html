Periferik qurğular

Kompüterin əsas blokundan kənarda olan və onun imkanlarını genişləndirən qurğulardır: məlumat daxil edir, çıxarır, saxlayır və ya ötürür. Qoşulma interfeysləri: USB-A/C, HDMI, DisplayPort, Bluetooth, Wi-Fi, 3.5 mm audio.

02
Hazırlıq

Qoşulmadan əvvəl 5 addım

1

Uyğunluq

İnterfeys (USB, HDMI) və əməliyyat sistemi dəstəyini yoxlayın.

2

Təhlükəsizlik

Quru əl, torpaqlanmış rozetka, zədəsiz kabel. Daxili qurğuları söndürülmüş halda qoşun.

3

Drayver

Rəsmi istehsalçı saytından son versiyanı yükləyin.

4

Yer seçimi

Havalandırma, ergonomika və səliqəli kabel düzülüşü.

5

Yeniləmə

Windows Update və BIOS/UEFI yeniləmələrini yoxlayın.

03
Printer

Printerin quraşdırılması

1 · Fiziki qoşulma

Qidalanma kabelini birləşdirin, kağız və kartric/toner yerləşdirin, USB ilə qoşun.

2 · Drayver

Modelə uyğun drayveri qurun; Windows çox vaxt onu özü tapır.

3 · Əlavə etmə

Settings → Bluetooth & devices → Printers & scanners → Add device

4 · Test çapı

Printer xassələrində «Print Test Page».

5 · Parametrlər

Defolt printer, A4, keyfiyyət, ikitərəfli çap, şəbəkə (IP) printeri.

05
Monitor

İkinci monitorun konfiqurasiyası

Settings → System → Display bölməsində ekranları tanıdın, düzün və parametrlərini seçin.

Win + PDuplicateExtendSecond screen only
  • Identify — ekranların nömrəsi, sürüşdürərək yerləşdirmə
  • Ayırdetmə — tövsiyə olunan (məs. 1920×1080), 60/144 Hz
  • Main display — əsas ekranın təyini
06
Drayverlər

Problemlərin aradan qaldırılması

🛠️

Device Manager (Win + X)

  • Sarı ünlem — drayver problemi
  • Update driver — avtomatik axtarış
  • Roll back driver — əvvəlki versiya
  • Uninstall device — təmiz yenidən qurma

Qurğu tanınmır

Başqa USB portu/kabel yoxlayın, kompüteri yenidən başladın.

Çap olunmur

«Offline» statusu və çap növbəsini yoxlayın, Print Spooler-i restart edin.

Səs / görüntü yoxdur

Defolt qurğu, səviyyə və məxfilik icazələrini yoxlayın.

Yavaşlıq / konflikt

USB hub əvəzinə birbaşa port, enerji qənaətini söndürün.
